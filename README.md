# Kahn's Algorithm for Topological Sorting

This project implements Kahn's Algorithm using Queue for Topological Sorting in Directed Acyclic Graphs (DAG) using the C programming language.

## Features
- Topological sorting of DAG
- Cycle detection
- Queue-based implementation
- Time Complexity Analysis
- Multiple test cases

## Technologies Used
- C Programming
- GCC Compiler
- Visual Studio Code

## Applications
- Task Scheduling
- Dependency Resolution
- Course Prerequisite Planning
- Workflow Management
